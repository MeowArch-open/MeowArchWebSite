# 启动！

当前文档大部分地方还只是占位符喵，正在施工！
:::
初始化完成，系统就跑起来了喵！这一步做几项基础检查，确认一切正常。

## 开机自检

- 确认能正常进入桌面喵。
- 检查 Wi-Fi、蜂窝网络与蓝牙是否可用。
- 打开相机、指纹等关键硬件试一下。

## 遇到问题？

[MeowArch 组织](https://github.com/MeowArch-open)反馈喵。
