## 自动构建

- 推送 / PR 触发 CI，自动拉取 manifest 并构建喵。
- 构建产物与校验值随 Release 一起发布。

## 贡献流程

1. Fork 并新建分支喵。
2. 提交改动，推送并发起 Pull Request。
3. 等待 CI 通过与维护者 review 后合并喵。
