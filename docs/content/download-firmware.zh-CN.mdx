# 下载固件
:::note note
当前文档大部分地方还只是占位符喵，正在施工！
:::
开始刷机前，先把对应机型的固件包下载好喵。

:::warning 认准机型
下错机型的包可能会导致无法开机喵！
:::

## 下载地址

- 前往我们的 [下载页](../../download.html) 喵！
- 或者前往我们的 [设备支持页](./status.html) 来找到你的设备喵！

## 校验完整性

下载完成后**记得检查**hash喵，猫猫可不背这锅喵：

```term
❯ sha256sum meowarch-*.zip
```

对照下载页给出的校验值，一致即可进入下一步喵。
